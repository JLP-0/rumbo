Under the hood

A backend-first system: the LLM plans and explains, a deterministic engine computes every number.

Generic goal model

No goal types hardcoded: metrics, routines and milestones describe any goal.

Validated LLM output

Structured outputs, Pydantic schemas and business rules, with retries and clarifying questions.

RAG over your history

pgvector search over past goals and notes, always scoped to the current user.

Safe tool calling

The assistant only calls read-only tools; the user identity comes from the JWT, never from the model.

Measured, not guessed

Evaluation datasets per prompt version and LLM-as-a-judge for generated reviews.

Reliable by design

Idempotency enforced by the database and an outbox for notifications that never get lost.
